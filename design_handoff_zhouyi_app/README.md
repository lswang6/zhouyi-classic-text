# Handoff: 周易卜卦 App（卜一卦 / 摇卦 / 解卦 / 卜卦记录）

## Overview
一款 iOS 周易卜卦应用。用户输入所问之事，选择起卦方式（铜钱摇卦 / 数字起卦 / 时间起卦），生成本卦与变卦，按朱熹《易学启蒙》动爻规则给出“断卦要点”，并可查看卦辞、爻辞（动爻高亮）、白话解读。每次卜卦自动保存，可搜索、按卦名筛选、收藏、填写应验反馈与备注。

## About the Design Files
本目录中的文件是用 HTML 制作的**设计参考**，用来展示预期的外观和交互行为，不是可以直接上线的生产代码。你的任务是在目标代码库现有的技术环境中（SwiftUI、React Native、Flutter 等）**按其既有模式重新实现这些设计**。如果还没有代码库，请为项目选择最合适的框架（iOS 原生建议 SwiftUI）。

- `Zhouyi App.dc.html`：完整的可交互原型。模板部分为 HTML（全部使用内联样式），逻辑部分位于 `<script data-dc-script>` 中的 `class Component`。
- `hexagrams.js`：六十四卦数据（卦名、全名、卦辞、白话要旨、六爻爻辞）、八卦表、文王卦序查表。**可以直接移植为 JSON 或 Swift 数据。**
- `support.js`：原型运行时，仅用于在浏览器中打开原型，实现时不需要。

## Fidelity
**高保真（hi-fi）。** 视觉基于 Adobe **Spectrum 2**（React Spectrum）设计系统：配色以中性色为主，强调色为 Spectrum 蓝，支持浅色/深色模式。目标代码库如果已有自己的设计系统，请沿用这里的布局、层级和交互，把 token 映射到自己的系统。

## 核心算法
- **铜钱**：每枚钱“背”记 3、“字”记 2，三枚之和：6 老阴（动）、7 少阳、8 少阴、9 老阳（动）。每次掷钱得一爻，共六次，自下而上排列。
- **本卦**：爻值 % 2 得到阴阳（1 为阳）。**变卦**：把动爻的阴阳翻转。
- **卦序**：下卦取第 0–2 爻、上卦取第 3–5 爻，匹配 `ZY_TRI` 得到八卦下标，再查 `ZY_KW[上][下]` 得到文王卦序。
- **数字起卦**：上卦 = n1 % 8（余 0 取 8），下卦 = n2 % 8，动爻 = n3 % 6（余 0 取 6）。八卦按先天数排列：1乾 2兑 3离 4震 5巽 6坎 7艮 8坤。
- **时间起卦**：年支数（子=1）+ 月 + 日 → 上卦；再加时支数 → 下卦；总和 % 6 → 动爻。**原型中月、日取公历，仅作示意，实际实现需要接入农历。**
- **断卦规则**：0 个动爻，看本卦卦辞；1 个，看本卦动爻爻辞；2 个，看两动爻爻辞，以上爻为主；3 个，看本卦与变卦卦辞，以本卦为主；4 个，看变卦两静爻爻辞，以下爻为主；5 个，看变卦静爻爻辞；6 个，乾卦用“用九”、坤卦用“用六”，其余卦看变卦卦辞。
- **爻名**：阳爻称“九”、阴爻称“六”，依位置写作初九、九二……上六。

## State Management
- 记录结构：`{ id, ts, q, cat, method: 'coin'|'number'|'time', lines: number[6], fav, note, verify: '待验'|'应验'|'未应验' }`。原型把记录存在 localStorage 的 `zy-records-v1` 中，实际实现建议改用本地数据库或云同步。
- 界面状态：`screen`（home/cast/reading/history）、`method`、`q`、`cat`、`nums`、`cast`（已得的爻值）、`coins`、`busy`、`shaking`、`curId`、`rtab`、`hq`（搜索词）、`hf`（筛选条件）。
- 摇一摇：原型监听 `devicemotion`，当加速度合值大于 28 时触发掷钱。iOS 原生可使用 `motionEnded(.motionShake)`。
